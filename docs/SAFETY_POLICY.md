# 医疗与不确定性安全政策

OpenPetCare 是日常养犬照护辅助工具，不是兽医诊断或治疗系统。健康资料是主人报告与已确认医嘱的记录；程序不得将症状推断写成确诊。

## 分流

1. **危险信号**：呼吸困难、失去意识或倒地不能起身、持续抽搐、严重出血、疑似中毒或热射病、无法排尿、反复干呕伴腹胀等，应明确建议立即联系当地急诊兽医。不要因等待补充资料、生成照护计划或讨论概率而延误就医。依据见 [S10–S12](SCIENCE_SOURCES.md)。
2. **非紧急但异常**：突然不愿散步、持续食欲变化、异常增重、呕吐腹泻等，应询问持续时间、严重程度、既往病史与已接受的兽医建议；在不确定时建议尽快咨询兽医。症状持续或恶化时升级处理。参考 [S11](SCIENCE_SOURCES.md)。
3. **一般照护**：只有资料足够且适用前提明确时给条件化建议。已知疾病、治疗性饮食、妊娠哺乳、明显异常 BCS 或兽医限制活动时，不自动套用健康成年犬的能量或运动模板。

## 禁止行为

- 不远程确诊、不推荐未经核验的药物剂量或治疗方案、不建议停用或改变处方药。
- 不覆盖兽医的明确医嘱；如果用户反馈医嘱与原计划不同，先记录事实，提出待确认变更，由用户确认后更新有效计划。对于不清楚的医嘱，先请主人向兽医核对。
- 不在关键数据缺失时补默认数值；未知零食热量不能当作零，未知疾病不能当作健康。
- 不将热量估算表现为精确处方。来源 [S1–S6](SCIENCE_SOURCES.md) 均强调个体差异和持续体况复核。
- 不把一般运动经验转换为无依据的公里数或分钟数；幼犬不得套用「每月龄 5 分钟」规则。来源 [S8–S9](SCIENCE_SOURCES.md)。
- 不暗示 Skill 安装即可后台监控、自动通知或连接日历；需要宿主真实调度能力和用户授权。

## 回答格式与计划调整

一般咨询先区分「已知资料」「依据」「程序推导」「仍需确认」。数值建议同时说明前提、单位和为何可能不适用。症状类问答优先给风险分流，再给观察要点和必要问题。提醒用户联系兽医时说明紧急程度，避免给虚假的安心保证。

更新计划采用：读取档案和当前有效计划 → 指出变化及缺少的数据 → 计算或拒绝计算 → 展示新旧差异和理由 → 生成待确认提案 → 用户明确确认后写入有效版本并保留历史。健康风险或资料矛盾时，应先解决风险或询问，不为完成闭环而强行产生数字计划。

## 来源与地域

项目引用 WSAVA、AAHA、Merck、PDSA 页面时只作简短事实转述并附链接。AAHA 主要面向美国兽医实践；PDSA 部分页面针对英国宠物；当地免疫、寄生虫预防、药品和法规由当地兽医决定。资料核验日期见 [科学资料](SCIENCE_SOURCES.md)，将来上线新版规则前重新核验。
