# 中文建档与资料补全引导

本文件供宿主 AI 在建档或每日照护资料不足时使用。目标是先替用户完成能自动完成的核验，再用中文提出最少、可回答的问题。不得把专业术语、网页查找或兽医咨询当作普通健康犬获得照护建议的默认门槛。

## BCS 体况评分

BCS（Body Condition Score，体况评分）是用外观和触摸估计犬只脂肪储备的 1–9 分量表，不是化验或疾病诊断。询问前先用中文说明检查方法：

1. 轻轻摸肋骨，感受是否容易摸到以及上方脂肪厚度。
2. 从上方看肋骨后方是否有腰身。
3. 从侧面看腹部是否向后上方收起。

不要一次向用户堆出九段文字。先让用户选择最接近的一组：

- **偏瘦（约 1–3）**：骨头明显，或肋骨几乎没有脂肪覆盖。
- **大致理想（约 4–5）**：肋骨容易摸到，俯视有腰，侧面腹线向上收。
- **偏胖（约 6–9）**：肋骨越来越难摸，腰身变浅或消失，腹线不再上收。
- **不确定**：保留 `bcs.score_9 = null`，不要强行映射分数。

用户选定分组后，再只展示对应细分项：

| 分数 | 中文自评摘要 |
| --- | --- |
| 1 | 远看多处骨性轮廓非常突出，几乎无脂肪，并有明显肌肉流失。 |
| 2 | 肋骨、腰椎和骨盆很容易看见或摸到，几乎摸不到脂肪，可能有轻度肌肉流失。 |
| 3 | 肋骨很容易摸到并可能看见，腰身与腹部上收非常明显。 |
| 4 | 肋骨容易摸到、脂肪覆盖很少，腰身和腹部上收清楚。 |
| 5 | 肋骨能摸到且没有多余脂肪，俯视有腰，侧面腹部上收。 |
| 6 | 肋骨仍能摸到但脂肪稍多，腰身不明显，腹部上收仍可见。 |
| 7 | 肋骨较难摸到，腰部或尾根有明显脂肪，腰身很浅或消失。 |
| 8 | 肋骨通常摸不到或需要明显用力，腰身和腹部上收消失，腹围可能增大。 |
| 9 | 胸、背、尾根等处有大量脂肪，颈部或四肢也可能堆积脂肪，腰身完全消失。 |

选定精确分数后，把当天写入 `bcs.recorded_at`；只选了粗分组或仍不确定时，不写入整数。厚毛犬以触摸肋骨为主。若出现明显肌肉流失、腹部异常膨大或触碰疼痛，不继续把外观硬套成分数，应按症状进行安全分流。主人可以自评；可建议以后在常规就诊时顺手复核，但这不是普通健康成年犬起始估算的前置条件。

依据：[WSAVA 犬只 9 分体况评分表（官方中文繁体版）](https://wsava.org/wp-content/uploads/2020/01/1-%E9%AB%94%E6%85%8B%E8%A9%95%E5%88%86%E8%A1%A8-%E7%8B%97.pdf)及 [2025 英文版](https://wsava.org/wp-content/uploads/2025/06/WSAVA_BCSCat_BCSDog_Nutrition_250612.pdf)。面向用户时使用上方原创简体中文摘要；图表版权归原作者所有，本仓库不复制原图。

## 狗粮资料主动检索

用户已经说过的品牌、系列或口味不要重复索取。先从对话提取：

- 品牌与完整产品线或系列；
- 口味或配方名；
- 干粮、湿粮、冻干或零食等形态；
- 幼犬、成犬、全生命阶段，以及体型或犬种细分版本；
- 购买国家或地区；只有出现多个地区版本时才追问。

宿主具备联网检索能力时，先主动查找精确产品，来源优先级如下：

1. 购买地区的制造商官方产品页；
2. 制造商官方标签 PDF、营养指南或产品手册；
3. 制造商官方客服公开资料。

监管或行业资料用于解释标签规则，不能代替具体产品数据。电商、零售商和搜索摘要只能作为寻找官方页面的线索，不能直接写入有效计划。

只有犬种对象、品牌、系列、配方或口味、形态、生命阶段或体型版本、地区均能对应时，才算精确匹配。不得拿同系列相似口味、猫粮、旧配方或其他地区版本补空。

唯一匹配后自动提取并向用户展示：

- 代谢能及原始单位；
- 统一换算后的 `kcal/kg`（以喂食状态计，即 as-fed）；
- 完整均衡或营养充分性声明；
- 适用生命阶段；
- 官方 URL、对应地区和访问日期。

把来源记录成可复核的中文文本，例如：

```text
制造商官方资料；产品：完整产品名；市场：中国大陆；
原始值：370 kcal/100g；换算：3700 kcal/kg（以喂食状态计）；
URL：https://...；访问日期：<实际访问日期>
```

### 可重复换算

- `kcal/100g × 10 = kcal/kg`
- `kcal/g × 1000 = kcal/kg`
- `kcal/杯 ÷ 官方克/杯 × 1000 = kcal/kg`
- `kcal/罐 ÷ 该罐净重克数 × 1000 = kcal/kg`
- `kJ/kg ÷ 4.184 = kcal/kg`
- `MJ/kg × 1000 ÷ 4.184 = kcal/kg`

每杯或每罐换算时，热量和克重必须来自同一精确产品的官方资料；不得猜测“一杯多少克”。官方已经给出 `kcal/kg` 时直接采用，不从喂食量表反推，也不依据保证分析的上下限自行制造假精度。

### 只有确实无法核实时才追问

- 多个地区版本：只问购买地区。
- 同名产品有干湿粮、幼成犬等多个版本：只问当前区分项。
- 官方页可能与包装批次不同或官方数据冲突：请用户抄写包装上的“代谢能 / Calorie Content（热量）”一行。
- 没有可靠官方数据：索取上述热量行、适用生命阶段和完整均衡声明，不让用户整理整张营养表。
- 宿主没有联网工具：明确说明当前无法联网核验，再索取这几个最小字段；不得假装搜索过。

依据：[WSAVA 选择宠物食品指南](https://wsava.org/wp-content/uploads/2021/04/Selecting-a-pet-food-for-your-pet-updated-2021_WSAVA-Global-Nutrition-Toolkit.pdf)、[AAFCO 标签阅读说明](https://aafco.org/consumers/understanding-pet-food/reading-labels)、[AAFCO 热量说明](https://aafco.org/consumers/understanding-pet-food/calories/)和 [FDA 完整均衡宠物食品说明](https://www.fda.gov/animal-veterinary/animal-health-literacy/complete-and-balanced-pet-food)。

## 数字建议的路径

兽医确认的每日热量目标是**已有时优先使用的可选输入**，不是普通健康成年犬获得数字的门票。资料满足程序条件时，直接运行 `daily` 并呈现 `estimated_starting_point` 的 kcal、每日克数、每餐克数、前提和局限，不得改写成“必须先问兽医”。

资料不足时按工具返回的 `next_actions` 处理：先引导 BCS、自行检索精确狗粮或询问用户是否有已知病史和限制，再重新运行工具。只有危险信号、已知疾病、治疗性饮食或已经存在的兽医限制才进入相应医疗安全流程。
