# v0.1 测试与验收计划

## 自动测试最低范围

1. **完整有效资料**：建档、读回、同日照护计算的输入来源和稳定结果；成年健康犬在 24–84 月龄、BCS 4–5/9、无相关病史/限制/危险信号、主粮标签完整均衡等条件满足时的通用起始估算；兽医确认热量目标的优先级；换粮提案、确认与历史版本。
2. **缺少关键资料**：未知字段仍为空；热量密度或其他计算必需输入缺失时不生成精确主粮克数，并列出待补资料及中文可执行下一步。缺 BCS 时返回自评引导动作；缺精确食品热量时返回先查制造商官方资料的动作；健康史未知时只询问主人已知情况，不把兽医目标列成普通缺失项。
3. **异常或矛盾资料**：负体重、无效日期、非法标签生命阶段、热量密度缺失或无效、损坏文件应明确报错或拒绝计算，不能覆盖已保存的好数据。
4. **潜在医疗风险**：活动限制、明显异常或急症描述应提示联系兽医；不得给禁忌条件下的常规运动方案或药量。
5. **持久化与恢复**：用独立进程写入后退出，再启动进程读取；备份、恢复、历史有效计划均仍可读。回滚不得覆盖更新后的年龄、体重、BCS、医疗、预防和兽医热量目标。
6. **输入与隔离**：昵称宽度和组合 emoji，数据目录与 Skill 目录隔离，测试不读取真实用户目录。
7. **低负担建档**：健康成年犬在没有兽医热量目标时仍生成非处方起始 kcal 和克数；安装包包含中文建档引导。BCS 可选择“不确定”并保持未填写；狗粮官方检索无法唯一匹配时才向用户索取包装热量行。自动测试只验证结构化动作和安装内容，真实联网检索须在有工具的宿主中人工验收。

自动测试只能证明程序规则与存储行为；科学内容仍要逐条对照 `SCIENCE_SOURCES.md` 的一手来源。

## 人工验收

在实际 Codex 客户端中安装 Skill，依次表达：“帮我建立一只狗的档案”“BCS 是什么，我不知道怎么填”“它吃某品牌某系列某口味的成犬粮”“告诉我它今天应该怎么吃、怎么运动”“我最近换了狗粮，需要调整吗”“确认更新这个方案”。检查 AI 使用中文解释 BCS 并提供两步选择；具备联网能力时先查精确产品的制造商官方资料，只在无法唯一匹配时追问地区或包装热量行；健康成年犬资料齐全且无兽医目标时仍呈现起始估算；提案未确认前有效计划不变。重启客户端后再次询问，核对档案、有效计划及历史。Claude Code 等宿主按实际安装路径、工具权限和数据持久化另行验收；未经实测不写通过。
