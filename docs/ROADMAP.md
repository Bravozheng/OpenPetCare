# 路线图

## v0.1：本地犬类 Skill

首发验收聚焦一只狗从建档、今日照护、换粮提案、明确确认、关闭宿主后再次读取的闭环。实现版本化本地数据、安全写入、历史恢复、备份与导入导出，以及资料不足、矛盾资料和医疗危险信号的测试。先在 Codex 本地宿主执行人工验收；Claude Code 的发现、调用和持久化另行实机验证后才能标注为已支持。

## 后续候选方向（未承诺）

1. 扩充经核验的犬类知识来源、犬种别名与生命周期特殊情形。
2. 在真实宿主权限和测试基础上，增加可选的日历或调度适配器；Skill 自身不提供后台推送。
3. 根据实际用户需求，评估 MCP/插件、PWA 或微信小程序入口；不预先引入账号和云同步。
4. 只有犬类质量稳定后，才评估猫及其他宠物。

不在首发范围：OCR、包装图片识别、打卡进度、医疗诊断、付费服务器和独立聊天页面。免费开源代码不保证第三方 AI 宿主免费。
